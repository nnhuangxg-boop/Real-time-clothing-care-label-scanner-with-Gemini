# Real-time clothing care label scanner with Gemini

[简体中文](README.md) | [English](README.en.md)

**打开摄像头，扫一眼衣服标签，就知道该怎么洗、能不能烘。**

这个项目来自一个很日常的烦恼：洗完衣服准备放进烘干机，却不知道哪件能烘、哪件会缩水。答案其实就在洗护标签上，但那些方框、圆圈、横线和小点，实在不容易记住。

于是有了这个小工具。打开手机网页，把摄像头对准标签，不用拍照、手动上传图片，也不用自己查符号表。它会自动选取画面，让 Gemini 读取标签上的文字和符号，把洗护要求变成容易看懂的说明。

它关注的就是两个问题：

- **能不能烘干？** 是否禁止滚筒烘干，或需要低温等条件。
- **应该怎么洗？** 是否可以水洗，需要什么温度，以及机洗或手洗的要求。

设计上尽量简单：无需安装、无需注册，支持中文和英文。打开就能免费体验，也可以填写自己的 Gemini API Key 继续使用。

希望它能成为洗衣服时顺手用一下的小工具，少查一次符号表，也少烘小一件喜欢的衣服。识别仍可能出错，画面模糊或信息不完整时会提示不确定；拿不准时，还是以清晰的原标签为准。
